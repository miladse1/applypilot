Fonts bundled for resume rendering. They let a tailored resume use the same (or a metric-compatible) typeface as the uploaded original.

- Carlito: metric-compatible with Calibri. SIL Open Font License 1.1 (Carlito-OFL.txt).
- Lato: SIL Open Font License 1.1 (Lato-OFL.txt).
- Tinos: metric-compatible with Times New Roman. SIL Open Font License 1.1 (Tinos-OFL.txt).

Source: https://github.com/google/fonts
